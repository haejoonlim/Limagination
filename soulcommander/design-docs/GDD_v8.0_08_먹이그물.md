# 복합 먹이 그물 재설계 제안서 (v8.0)

> [!info] 이 문서는?
> 현재 103종 64간선 그물을 **바이옴별로 복합적인 먹이 그물(weave)** 로 재설계하는 제안서.
> **상위 기준**: [[GDD_v8.0_00_확정사항]] · [[GDD_v8.0_07_통합생태계]] §8 (로지스틱·LV·10% 법칙 — audit_sim 22검사 통과 기반)

---

## 1. 목적 & 범위

- **목적:** "각 바이옴이 제각각인 그물"을 "탑 전체가 하나로 흐르는 복합 그물"로 — 종이 아니라 **관계**가 콘텐츠가 되게 한다.
- **범위 (in):** 먹이 관계(prey/predators) 재설계 · 사체·부식 경로 신설 · 전투몬의 그물 역할 부여 · 바이옴별 간선 목표치
- **비범위 (out):** 새 몬스터 대량 추가(리스퍼드 최소화) · 스탯·패턴 변경 · 도감 UI (별도)

## 2. 진단 — 지금 그물이 얇은 이유 (2026-09-15 전수 측정)

| 지표 | 현재값 | 평가 |
|---|---|---|
| 종간 간선 | **64개** (103종) | 종당 0.62 — 성숙 먹이그물(종당 2~4)의 1/5 수준 |
| 그물 고아종 | **46종** (45%) | prey·predators 둘 다 0 — 그물에 안 걸린 종이 절반 |
| 사슬 최대 깊이 | 4 (유안티·거미여왕·비홀더) | 얕음 — 대형 apex가 바로 1차 소비자를 먹는 구조 |
| 단방향(비대칭) 관계 | **35개** | A.predators에 B 있는데 B.prey에 A 없음 — 데이터 정합 55% |
| 사체 경로 | **0건** | 분해자 21종인데 "사체를 먹는다"는 명시 없음 — 영양물질 순환 미완성 |
| 자원 종류 | 30종 (참조 58) | 하수도 슬러지·먹광 등 근원자원과 ecology 자원명 불일치 혼재 |

**핵심 병목 3가지:**
1. **신규 서식종 34종이 전부 고아** — 1·2차 배치 때 먹이 관계를 못 붙임 (이번 대화에서 도감은 완성했지만 간선은 안 이었음)
2. **언데드·정령이 그물 밖** — 스켈레톤·좀비·리치 11종이 "비생물이라" 이유로 고아. 그러나 세계관상으로 언데드는 **생명력(에테르)을 흡수**하는 존재 — 그물에 묶을 구실이 충분하다
3. **전투몬이 그물에 안 걸림** — 50종 중 그물 기여가 있는 종은 극소수. 전투와 생태가 분리된 설계(07 §5)가 관계 데이터까지 분리시켜 버림

## 3. 설계 원칙

| # | 원칙 | 이유 |
|---|---|---|
| 1 | **간선 우선, 종 최소** — 새 종 추가는 최후 수단, 관계를 이어붙여 복잡도를 만든다 | 리스퍼드 원칙. 도감 103종은 이미 충분 |
| 2 | **모든 종 최소 2간선** — 먹이 1 + 천적 1 (생산자·최상위는 예외) | 고아 46종 제거가 1차 목표 |
| 3 | **전투몬도 그물에 건다** — 전투층과 생존층은 분리하되 관계는 공유 (07 §5 확장) | 몬스터 밀도 높은 바이옴(폐허 13·동굴 12·산맥 11)이 그물에 기여하게 |
| 4 | **언데드·정령은 '에테르 경로'로 참여** — 사체·영혼·마력을 먹는 존재로 그물에 편입 | 세계관 정합 + 고아 제거. 10% 법칙은 생물 사슬에만 적용 (06 §3.5 면역 규칙과 동일) |
| 5 | **사체 흐름을 명시한다** — 모든 죽음은 `corpse` 자원으로, 분해자·청소부·언데드가 섭취 | 영양물질 순환 (07 §8) 완성. v7.12 검증 역학 승계 |
| 6 | **쌍방 정합 강제** — A.predators에 B → B.prey에 A (35건 비대칭 전부 해소) | 시뮬레이터·도감 상호참조가 정확히 도는 전제 |
| 7 | **바이옴별 간선 목표** — 대형 8+, 중형 5~7, 소형 3~4 (섬생물지리학: 면적=K) | 20바이옴 공평 시작이 아니라 K 기반 편차 |

## 4. 그물 구조 — 5가지 경로 유형

기존의 직선 사슬(풀→토끼→매)에 4가지 경로를 추가해 **그물**을 만든다.

| 경로 | 흐름 | 예 | 게임 효과 |
|---|---|---|---|
| ① **청소 경로** | 모든 죽음 → `corpse` → 청소부(썩고기갑충·바퀴벌레·오우즈) | 사막쥐 사망 → 썩고기갑충 부스트 | 사냥하면 그 층 청소부가 늘어남 — 2차 효과 |
| ② **부식 경로** | 분해자 → 근원자원 회귀 (`detritus→soil` 암묵) | 부패균 → 과실 K 부스트 | 분해자를 죽이면 그 층 먹이층 K가 떨어짐 — 생태 피드백 |
| ③ **에테르 경로** | `soul`·`mana`·`corpse` → 언데드·정령 | 좀비가 사체를, 리치가 영혼을 흡수 | 언데드층이 생물층과 결합 — 묘지·폐허 특유의 어둡고 복잡한 그물 |
| ④ **기생·약탈 경로** | 동종간/준동종 착취 (기생·알훔치기·영역 약탈) | 유안티→거미여왕 알 · 하수뱀→골목쥐 | 직선 사슬로 표현 안 되는 복잡도. 관계 유형 필드로 표기 |
| ⑤ **담당자 스위치** | 같은 자원을 시간대별로 다른 종이 섭취 (주간·야행성 분업) | 낮 매 ↔ 밤 어스름매 | 이미 activity 필드 존재 — 활용만 하면 됨 |

## 5. 몬스터 그물 편입 명단 (제안)

### 5.1 언데드·정령 — 에테르 경로 (고아 11종 해소)

| 종 | 섭취 | 이유 |
|---|---|---|
| 스켈레톤·좀비·스켈레톤 워리어 | `corpse` (사체) | 언데드의 원료 — 사체 경로와 직결 |
| 스켈레톤 메이지·리치 | `soul`·`mana` | 영혼 마법 사용자 — 세계관 그대로 |
| 밴시 | `soul` | 원혼을 먹는 전승 그대로 |
| 스켈레톤 야차 | `corpse`·`soul` | 동양 언데드 변형 |
| 수호령·아아시마르·드레드노트 | `mana` | 정령·천사형 — 마력 섭취 (섭취≠기생, 수호령은 신전 성수 이슬과 연결) |
| 오우즈 | `corpse` | 분해자 role 유지 — 사체 경로의 동굴 담당 |

### 5.2 전투몬 — 생물 사슬 편입 (밀도 높은 바이옴 우선)

| 바이옴 | 편입 제안 (전투몬 → 먹이) | 효과 |
|---|---|---|
| 폐허 (전투 13종) | 드레드노트가 골목쥐·바퀴벌레 섭취 · 골렘류는 `detritus`(무기물) | 폐허 그물 간선 0 → 5+ |
| 동굴 (12) | 트롤·오거가 동굴박쥐·동굴버섯 섭취 (기존 관계 유지+확장) | 동굴 사슬 깊이 4 유지 + 하위 확장 |
| 산맥 (11) | 거대 곰이 고산쥐·산양 섭취 · 스톰 자이언트는 `mana`(뇌전) | 산맥 하위층 2종 → 그물 참여 |
| 심해 (7) | 크라켄 촉수→심해조개 (기존) + 심해뱀→심해플랑크톤 군체 추가 | 심해 swarm 경로 완성 |
| 지옥 (5) | 발록·헬하운드가 유황파리·불열매 섭취 | 지옥 열생태 완결 |

### 5.3 제외 유지 (그물에서 빼는 것)

- **원소 정령 6종** (파이어·워터 엘리멘탈 등) — 물질순환 밖 존재. 에테르 경로도 불필요(스스로 자원). 그물 제외 유지, 역할 elemental
- **미믹** — 사냥이 아니라 매복. 관계 없음 유지 (니치 분화 원칙)

## 7. 데이터 스키마 확장 (가안)

```json
"ecology": {
  "prey": [{"id": "mon_rat_01", "type": "predation"}],   // 기존 + 유형 확장
  "preyResources": ["grass", "corpse", "soul"],           // 자원을 prey에서 분리 (P5 제안 3 승계)
  "predators": ["mon_hawk_01"],
  "relationTypes": {"mon_rat_01": "predation", "mon_carrionbeetle_01": "scavenge"},
  "activity": "nocturnal"                                  // 기존 — 담당자 스위치에 활용
}
```

- `prey`를 **종간(predation/parasitism/kleptoparasitism)** 과 **자원(resource)** 으로 분리 — 07에서 제안했던 prey 분리(제안 3)를 여기서 실시
- `corpse`·`soul`·`mana`는 **전역 자원**으로 정의 — 모든 바이옴 공통 (사체는 어디나 생김)

## 8. 구현 순서 (T-08 작업 목록)

> **실행 결과 (2026-09-15, T-08-1~4 완료):** 종간 간선 64 → **118** · 비대칭 35 → **0** · 고아종 46 → **0** (elemental·mimic 제외).
> 도구: `design-docs/_tools/gen_foodweb.py` (멱등). 검증: check_docs 그물 메트릭 상시화 + audit_sim 22검사 통과.
> 미구현 계획종(성수달팽이·슬러지장구벌레·심해조개·동굴박쥐·송곳매)은 실존종으로 대체 연결 (마녀 해파리·폭풍매·크라켄 촉수·산호초 여과 경로).

| # | 작업 | 성격 | 비고 |
|---|---|---|---|
| T-08-1 | `corpse`·`soul`·`mana` 전역 자원 정의 + 분해자·언데드 21종 preyResources 부여 | 데이터 | ✅ 고아 46종 중 21종 즉시 해소 |
| T-08-2 | 신규 서식종 34종 간선 부여 (바이옴 근원자원 → 먹이층 → 포식층) | 데이터 | ✅ 07 §4 표 기반 — 기계적 |
| T-08-3 | 35건 비대칭 관계 쌍방 정합 수정 | 데이터 | ✅ check_docs 자동화 검증 추가 |
| T-08-4 | 전투몬 10종 생물 사슬 편입 (§5.2) | 데이터 | ✅ 트롤 제외 — 골렘 detritus·발록·헬 하운드·크라켄 촉수·거대 곰·거미 여왕 |
| T-08-5 | relationTypes 필드 도입 + 도감 표기 (포식/기생/청소 아이콘) | 데이터+UI | ⬜ 도감 상호참조와 연결 |
| T-08-6 | audit_sim에 그물 메트릭 추가 (종당 간선·고아율·사슬 깊이·비대칭 0건) | 도구 | ✅ check_docs에 상시화 (간선≥100 · 고아0 · 비대칭0) |
| T-08-7 | 도감 먹이사슬 그래프에 경로 유형 색상 (청소·에테르 구분) | UI | ⬜ 시각적 복합도 체감 |

**예상 효과:** 스폰 가중치가 단순 밀도가 아니라 **관계 밀도** 기반이 됨 — "이 층엔 먹이가 풍부한가"가 "이 층엔 그물이 촘촘한가"로 진화. 게임 체감으로는 같은 층이라도 사냥 순서에 따라 생태 반응이 달라지는 복합성이 생김.

## 9. 미결정 & 리스크

- **간선 상한** — 종당 3을 넘으면 시뮬가 불안정해질 수 있음 (audit_sim으로 상한 검증 필요)
- **전투몬 개체수** — 전투몬을 그물에 넣으면 "몬스터가 밀도 조절당하는" 설정이 필요. 전투 스폰은 별도 시스템이므로 **관계만 공유하고 개체수는 비연동**으로 시작 (미정M)
- **언데드 에테르 경로의 세계관 승인** — "언데드가 사체를 먹는다"는 설정 확정 필요 (사용자 결정 사항)
