# 전투력(CP) + 등급계수 v1.0 가안 (v8.0)

> 전부 **가안**. 플탐에서 튜닝. 방향만 확정용.
> 최종갱신: 2026-09-14

## 1. 소환 원칙 (C 종결)

- **등급 × 종족 완전 독립.** 몇 성이 뜨든 종족 상관없음. 어둠 ★5가 두 명 나와도 정상.
- **템플릿 강제 없음.** 기존 16템플릿(시온~블라드)은 외형·스킬 원형 풀(참고자료)로 강등.
- 블라드 ★5 고정 게이트 **폐지**. ★5는 그냥 강한 개체.
- C항 종결. 결정할 거 없음.

## 2. 등급계수 (★1~★7)

| 등급 | 계수 | 전 등급 대비 | 비고 |
|---|---|---|---|
| ★1 | ×1.00 | — | 기준 |
| ★2 | ×1.30 | +30% | **등급당 1.3배 복리 곡선 (2026-09-14 2차 개정)** |
| ★3 | ×1.69 | +30% | 1.3² |
| ★4 | ×2.20 | +30% | 1.3³ |
| ★5 | ×2.86 | +30% | 1.3⁴ |
| ★6 | ×3.71 | +30% | 1.3⁵ (뽑기) |
| ★7 | ×4.83 | +30% | 1.3⁶ — 초월진화 전용 (뽑기 제외) |

- 명조식(★1~7 ×1.0~3.5) → **등급당 1.3배 복리**로 재개정 (기존 ×1.15~3.5 폐기). ★5는 ★1의 2.86배.
- **몬스터 스케일 정합** (monsters.json threatBase — 2026-09-14 확인): tier1 18~25 · tier2 42~65 · tier3 45~95 · tier4 85~115 · tier5 125~160
  - 영웅 ★n 등급곡선(×1.3^n)과 몬스터 tier 배율(tier당 약 ×1.5)은 **별개 곡선** — 영웅이 빠르게 성장하는 구조
  - 탑 층 진행 시 몬스터 tier 상향(층 스케일식 + FB-07 −15%)이 어려움 담당, 영웅 등급은 파밍 리턴이 담당
  - ★6·★7 등급상승(×3.71·×4.83)은 몬스터 대비 과열 가능 — 플탐에서 층 스케일(00 미정G)과 함께 재조정
- 레벨 곡선(D-172, 전등급 Lv100)은 기존 그대로 사용. CP는 그 위에 곱함.
- **영웅 기준스탯 (가안 — 13종은 05 §7, 상위 요약):** HP 500 / ATK 45 / DEF 20 / ASPD 10 / MAG 20 → `races.json` `meta.heroBaseStats`
  - 필드스탯 = 기준 × (1 + 종족 statMods%) × 등급계수 × 레벨계수 (ASPD는 등급계수 미적용) · 플탐 튜닝
  - 하위 8종 (PEN·EVA·CRI·CDMG·MANA·SPD_CAST·STA·MDEF)은 05 §7 산식 따름
  - MAG 20은 CP ①식용 가안 (P3-4, 2026-09-14) — 전투 피해식에는 아직 미사용
- **레벨계수 가안:** `1 + (Lv−1) × 0.05` (Lv100 ×5.95) — D-172 곡선 미제공으로 유지 (2026-09-14). 레벨업 필요 경험치 미구현

## 3. 전투력(CP) 공식 v1.0 가안

```
S = HP×0.12 + ATK×2.0 + MAG×2.0 + DEF×1.5 + MDEF×1.5
  + ASPD×3.0 + SPD_CAST×2.0 + CRI×3.0 + CDMG×1.0
  + PEN×2.5 + EVA×2.5 + MANA×0.05 + STA×0.03          … ① 기본스탯점수 (13종 — 05 §7 개정 동기화)
G = S × 등급계수(§2) × 레벨계수(기존 곡선)              … ② 성장점수
E = 장비 스탯의 ①식 합산                               … ③ 장비점수
K = 스킬 합산 (일반1 / 희귀2 / 영웅3 / 전설5 / 신화8)   … ④ 스킬점수
P = 성격보정 0.95~1.10 (§4)                            … ⑤
C = 상태보정 0.80~1.10 (사기·스트레스·Sanity 합성)      … ⑥
R = 공명보정 1.00~1.10 (해당계열 편성 3명마다 +5%, 상한) … ⑦

CP = round((G + E + K) × P × C × R)
파티CP = 출격 5명 합산
```

- **CP는 날것(raw) 수치.** 상성·지형·위치보정은 실전 보정으로 제외.
- ③ 장비 최소 세트 가안 (P3-3, 2026-09-14): 3슬롯(무기·방어구·장신구) × 3등급 = 9종 · 강화 +0~+10 · +1당 기본치 +10% · 강화비 골드 100×다음단계 → `unity/Assets/Resources/Data/equipment.json` · 획득 = 허브 상점 골드 구매 (하급 200 · 중급 800 · 상급 2,000G 가안) · 사망 시 보관함으로 반환
- ④ 스킬 (P3-4, 2026-09-14): 슬롯 구조만 — K = 희귀도 점수 합, 스킬 데이터·획득은 후속 (현재 K=0)
- 권장CP 가안 (P3-4, 2026-09-14): 해당 층 적 편성의 ①식 점수 합 × 1.0 (게이트키퍼는 보스 스케일 반영) · **유효CP는 지형 상성 데이터가 생길 때까지 날것과 동일 표기**
- 표시: `CP 12,400 (유효 ~13,800, 수해지형)` — 날것 + 예상유효 병기.
- 용도: 게이트 입장 권장CP · 오토매칭 · 랭킹. 입장 제한(컷)은 두지 않음 (도전 허용).

## 3-2. 수집 공명 tier5/tier7 (가안 — 효과·수치 전부 잠정, 플탐 전 재조정)

- CP 공식의 R은 tier3(해당계열 편성 3명마다 +5%, 상한)만 사용. 아래는 CP에 합산하지 않는 수집형 별도 효과.
- tier5: 동계열 5명 보유 → 계열 고유 패시브 해금 (`races.json` lineages[].passive5)
- tier7: 동계열 7명 보유 → 해당 계열 궁극기 피해량 +20%
- 판정은 보유(소유) 기준, 버프 적용은 출격 멤버 기준. 전투 중 사망 시 재계산.
- 데이터 실체: `unity/Assets/Resources/Data/races.json` resonance (값은 잠정 유지)

## 4. 성격보정표 가안

| 성격 | 보정 | 방향 |
|---|---|---|
| 용감 | ATK +5% (P≈1.03) | 공격형 |
| 신중 | DEF +5% (P≈1.02) | 방어형 |
| 냉정 | CRI +3% (P≈1.02) | 치명형 |
| 광폭 | ATK +8% / DEF -3% (P≈1.04) | 하이리스크 |
| 헌신 | 치유 +10% (P≈1.02, 힐러만) | 지원형 |
| 교활 | 회피 +5% (P≈1.02) | 회피형 |
| 무자비 | 치명타 피해 +10%p (P≈1.03) — 2026-09-14 중립 대체 신규 | 치명타형 |

- 성격은 CP에 ±10% 이내로만 영향. 성격 때문에 등급이 뒤집히지 않게 상한.
- 기존 성격 시스템의 특성 목록과 매핑은 후속 (특성명 확정 후).
- **부여·적용 가안 (P3-5, 2026-09-14 / 4차 개정 동일일):** 영웅 생성 시 **13종 가중치 롤** (용감·신중·고집 9 · 냉정·광폭·헌신·교활·무자비·불굴·성실 8 · 낭만 7 · 천애 2 — 백전노장은 Lv30+ 재롤 전용) · 10연차 내 중복 방지 · CP의 P에 반영 + **전투 계열 보정은 스탯에도 실반영** (ATK·DEF·CRI·EVA·CDMG·MAG 계열 — 05 §5 4차)
- **성격 13종 확정 (2026-09-14 3·4차)**: 성실 신규 (경험치 +5% · 생활·시설 적성 효율 +5% — 성장 균형형) · **요행 삭제** (자동전투에서 마지막 타격 주체가 랜덤이라 체감 불가) · **중립 삭제 → 무자비 신규** (치명타 피해 +10%p — 중립 확률 과다 체감, 사용자 결정) · 천애 미달 시 중립 전환 폐지 → 가중치 재롤 · 상세는 05 §5

## 5. 상태보정 가안

- 사기 높음 +5% / 보통 0 / 낮음 -5%
- 스트레스 높음 -5% / 한계 -10%
- Sanity 경고 -5% / 위험 -10%
- 합성 하한 0.80 (아무리 망가져도 80%는 나옴)
- **Sanity 게이지 가안 (P2 병원 — 2026-09-14):** 영웅별 0~100 · 시작 100 · 전투 참가 -5 · 아군 사망 목격 -10/명 · 병원 요양(허브 복귀) 병상 2명 +10 (04 §3.10 L1) · 경고 <50 / 위험 <25 (가안, P3-5)
- **합성 가안 (P3-5, 2026-09-14):** C = clamp(1 + 사기 + 스트레스 + Sanity, 0.80, 1.10) · 사기·스트레스는 영지(식당·추모·숙소) 전까지 영웅별 수동 설정값
