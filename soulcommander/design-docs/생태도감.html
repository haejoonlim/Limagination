생태 먹이사슬·개체수 — 게임이 '살아있는' 이유 · 17개
생태★ 로지스틱 성장개체수는 무한히 늘지 않고 한계(K)에서 멈춘다
Logistic Growth
dN/dt = r·N·(1−N/K)

개체수가 처음엔 폭발적으로 늘다가, 환경 한계에 가까워지면 성장이 멈추는 S자 곡선. 자연의 개체수 증가는 거의 항상 이 모양.

→ 게임 매핑: 바이옴별 개체수 상한 — 스폰 캡과 사냥 개체수 조절의 기본식. 하단 시뮬레이터의 초록 선이 이 곡선.

생태수용력그 환경이 먹여 살릴 수 있는 최대 개체수
Carrying Capacity (K)
K = 자원 등급 × 공간 크기

그 환경이 먹여 살릴 수 있는 최대 개체수. K를 넘으면 기아로 개체수가 다시 떨어진다.

→ 게임 매핑: 근원자원 풍요도 → 바이옴별 K. 사막(K 35)과 정글(K 130)의 체감 차이가 여기서 나온다.

생태★ 로트카-볼테라먹이 늘면 포식자 늘고, 포식자 늘면 먹이 줄고 — 주기 파동
Lotka-Volterra
dN/dt = rN(1−N/K) − aNP
dP/dt = baNP − dP

포식자와 피식자의 개체수가 서로 물고 물리며 주기적 파동을 만드는 모델. 토끼가 늘면 여우가 늘고, 여우가 늘면 토끼가 줄고.

→ 게임 매핑: 조우율·사냥 가치의 시간 변화 — 시즌마다 사냥감이 많은 층/적은 층이 달라지는 이유. 시뮬레이터의 빨강·초록 파동.

생태영양 단계 · 10% 법칙단계가 올라갈수록 에너지는 1/10 — 최상위 포식자는 늘 소수
Trophic Levels · 10% Rule
먹이 10 → 포식 1

에너지는 단계가 올라갈수록 약 1/10만 전달된다. 그래서 최상위 포식자는 항상 소수.

→ 게임 매핑: 스폰 테이블 비율 설계 — 먹이 10 : 포식 1. 서고 카드의 4종 사슬 배분도 이 법칙을 따름.

생태영양급위상위 포식자가 사라지면 그 아래가 폭발한다
Trophic Cascade
상위 제거 → 하위 폭발

최상위 포식자가 사라지면 그 아래 단계가 연쇄적으로 폭발하거나 붕괴한다. (옐로스톤 늑대 복귀 사례)

→ 게임 매핑: 보스 처치 후 2~3시즌 하위종 폭증 이벤트 — 사냥 보너스·생태 변동으로 연결 가능.

생태섬생물지리학섬이 크고 본토와 가까울수록 종이 많다 — 5층 블록=섬
Island Biogeography
종수 ∝ 면적 · 연결도

섬이 클수록, 본토와 가까울수록 더 많은 종이 산다. 작고 고립된 섬은 종수가 적다.

→ 게임 매핑: 5층 블록 = 섬. 근원자원 K가 곧 면적, 생태 통로(공유종)가 곧 거리 — 통로 37개로 탑 전체가 하나로 연결.

생태니치 분화 · 경쟁 배제같은 자리·같은 먹이면 두 종은 공존 못 한다
Niche · Competitive Exclusion
같은 자리 · 같은 먹이 → 한 종만 생존

완전히 같은 역할을 하는 두 종은 공존할 수 없다. 그래서 종들은 각자 다른 자리를 만든다(니치 분화).

→ 게임 매핑: 바이옴당 역할 중복 금지 — 신규종 habitat 단일 원칙의 근거. 같은 먹이를 노리는 종은 먹이를 나눠 먹도록 설계.

생태r/K 전략많이 낳고 빨리 늘는 종 vs 적게 낳고 크게 사는 종
r/K Selection
r전략: 많이 낳고 빨리 늘어
K전략: 적게 낳고 크게 산다

벌레·쥐 같은 r전략종은 개체수 회복이 빠르고, 용·곰 같은 K전략종은 느리지만 한 마리가 강하다.

→ 게임 매핑: swarm 계열은 사냥해도 금방 채워지고(하수도), apex는 한 번 잡으면 오래 비어 있다(정점) — 사냥 경제의 밸런스 축.

생태생태 천이무너진 생태는 정해진 순서로 서서히 회복된다
Ecological Succession
빈 땅 → 풀 → 덤불 → 숲

교란(화재 등)으로 생태가 무너져도 정해진 순서로 서서히 회복된다.

→ 게임 매핑: 리셋 주기 직후의 바이옴 재생 단계 — 갓 열린 층은 먹이종만 있고 포식자는 나중에 돌아온다 (미정J와 연결).

생태핵심종 · 지표종하나 빠지면 생태 전체가 바뀌는 종 / 건강도를 알리는 종
Keystone · Indicator Species
핵심종: 생태를 떠받치는 종
지표종: 건강도를 알리는 종

핵심종 하나의 부재가 생태 전체를 바꾼다. 지표종의 개체수로 생태 건강 상태를 알 수 있다.

→ 게임 매핑: 쥐 = 지표종 (개체수 = 층 건강 게이지) · 정점 보스 = 핵심종 — 도감에 생태 역할 표기

생태침입종천적 없이 들어온 종은 제멋대로 폭발한다
Invasive Species
천적 없는 종의 폭발

천적 없이 들어온 종은 로지스틱의 브레이크 없이 폭발한다.

→ 게임 매핑: 과거 31~75층 데드존 사례 — 포식자 없는 밴드의 위험. check_docs 역할 검사가 방지 장치.

생태영양물질 순환죽은 것은 분해자를 거쳐 다시 자원이 된다
Nutrient Cycling
사체 → 분해자 → 자원

죽은 것은 분해자를 거쳐 다시 근원자원이 된다. 순환이 끊기면 생태도 끊긴다.

→ 게임 매핑: 처치 사체 → 분해자 부스트 (v7.12 검증 완료 역학 승계안) — 사냥이 바이옴 자원에 미치는 영향.

생태기능반응 곡선사냥감이 아무리 많아도 포식 속도엔 한계가 있다
Holling's Functional Response
타입 II: 포화형 / 타입 III: S형

사냥감이 많아져도 포식자의 포식 속도엔 한계가 있다(포화). 타입 III은 사냥감이 적을 때 잘 안 잡다가 일정 수를 넘으면 폭발적으로 잡는다 — 피식자 멸종 방지 장치.

→ 게임 매핑: 사냥 피로도·자동 사냥 효율 캡 — 밀도가 낮은 층에서 무한사냥 방지. AI 몬스터 포식 속도에도 동일 적용. (06 §3.5 온도와 결합 시 계절별 사냥 효율 변동)

생태온도 의존성 · 열성능 곡선최적 온도에서만 최고 성능 — 벗어나면 급락
Thermal Performance Curve
최적 온도 T_opt에서 성능 최대 — 멀어질수록 급락

모든 생물은 잘 활동하는 온도가 정해져 있고, 최적점에서 벗어날수록 활동 능력이 급격히 떨어진다.

→ 게임 매핑: 종별 온도 내성(min~max) 필드 — 이미 73종 전종에 존재. 바이옴 band 밖 종은 스폰 게이트에서 차단 (06 §3.5).

생태베르그만 법칙추운 곳 생물은 몸집이 크다
Bergmann's Rule
추울수록 몸이 커진다

같은 계열이라도 추운 지역 종이 몸집이 크다 — 체적 대비 체표면적이 작아 열을 덜 잃는다.

→ 게임 매핑: 산맥·심연·정점 = 거대종 위주 — 거대 곰·트롤·스톰 자이언트·레비아탄 배치가 이미 이 법칙을 따름. 신규종 설계 지침으로 명문화.

생태앨런 법칙추운 곳 생물은 귀·꼬리 같은 돌기가 짧다
Allen's Rule
추울수록 귀·꼬리 등 돌기가 짧아진다

추운 기후의 동물은 열 손실 부위(귀·다리·꼬리)가 짧다.

→ 게임 매핑: 신규종 비주얼 가이드 — G1 한파 바이옴(산맥·동굴 상층) 종은 돌기 짧게. 도감 아이콘 일관성 규칙.

생태바이오루미네센스어두운 곳에서 생물이 스스로 빛을 낸다
Bioluminescence
빛으로 소통 · 먹이 유인

햇빛 없는 심해·동굴에서 생물이 스스로 빛을 낸다 — 먹이 유인·의사소통·위장 수단.

→ 게임 매핑: 심해·동굴의 시야 시스템 — 발광 종은 어둠 속 시야 범위 제공. 동굴 바이옴 '조명 반경 -40%' 모디퍼와 정합 (06 §3.2).

밸런스 성장·제한 — 숫자가 폭주하지 않게 하는 법칙 · 2개
밸런스체감 효용같은 투자를 반복해도 체감 효과는 점점 줄어든다
Diminishing Returns
효과 = X/(X+C) 형태

같은 투자를 반복해도 실제 체감 효과는 점점 줄어든다. 무한 강화 방지의 기본.

→ 게임 매핑: DEF/(DEF+200) 데미지 감소식 — AGENTS §4에 이미 확정. 온도 내성·Sanity 회복에도 동일식 적용 권장.

밸런스멱함수 성장요구량이 거듭제곱으로 늘어난다 — 초반 빠르게, 후반 느리게
Power Law
Y = a·X^b

필요 경험치·강화 비용이 레벨의 거듭제곱으로 늘어난다 — 초반 빠르게, 후반 느리게.

→ 게임 매핑: Lv100 곡선·영혼석 합성 비용 (P3-1) — b≈2~2.5 가안. 생태 개체수 회복 속도에도 적용 가능 (r전략종 b 낮음).

경제·시뮬 재화·변동 — 시스템이 도는 법칙 · 3개
경제·시뮬수요공급 · 동적 가격재고가 많으면 싸지고, 부족하면 비싸진다
Supply–Demand Pricing
가격 = 기본가 × (목표재고/현재재고)^k

재고가 많으면 내려가고 부족하면 오르는 가격 변동 — 시장의 기본 원리.

→ 게임 매핑: NPC 상점·사냥 재료 판매가 변동 — 과잉 사냥된 재료는 값 떨어짐 → 자연스러운 자원 분산 유도 (P3 이후 후보).

경제·시뮬싱크와 소스돈이 나오는 통로와 들어가는 통로의 총량을 맞춘다
Sink & Source
발행(소스) = 회수(싱크) 유지

퀘스트·드롭으로 돈이 새로 생기면(소스), 강화·세금으로 돌아가는 통로(싱크)가 반드시 필요하다. 균형이 깨지면 인플레이션.

→ 게임 매핑: 골드100×층·영혼석 층×30(소스) ↔ 소환티켓130석·합성·병원(싱크) — 이미 존재하는 경제 설계. 사냥 재화 추가 시 재계산 필수.

경제·시뮬마르코프 연쇄다음 날씨는 현재 상태만으로 확률적으로 결정된다
Markov Chain
다음 상태 = f(현재 상태)만으로 결정

날씨·환경이 현재 상태에서만 확률적으로 다음 상태로 넘어간다 — 기억 없는 자연스러운 변동.

→ 게임 매핑: 시뮬레이터 계절제 시연 구현 — 한파·평년·폭엔 3상태 전이확률행렬(유지 0.60)이 온도를 흔들고, 열성능 φ가 r·K·d를 진폭 → 계절마다 파동 변화. 층 진입 기온 전환은 계절제 확장 후보 (06 §3.5·미정L).
