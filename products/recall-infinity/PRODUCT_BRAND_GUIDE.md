## 1. 제품의 정체성

Recall Infinity는 학습 계획, 복습, 집중, 학습 진행 관리를 돕는 앱이다.

**제품 경험 목표**

공부를 부드럽게, 함께.

이 문장은 Recall Infinity의 제품 경험을 설명한다. LIMAGINATION 전체의 매니페스토나 회사 신조로 사용하지 않는다.

제품이 해결하려는 문제는 학습자가 해야 할 일을 정리하고, 학습 흐름을 유지하며, 자신의 진척을 이해하는 과정에서 생기는 부담을 낮추는 것이다.

## 2. 회사 브랜드와의 관계

| 구분 | LIMAGINATION | Recall Infinity |
|---|---|---|
| 역할 | 회사·상위 브랜드 | 개별 앱·제품 |
| 기준 | 브랜드 헌장 | 제품 가이드와 앱 소스 |
| 결정 범위 | 미션·비전·가치·회사 자산 | 기능·UI·UX·제품 말투·앱 아이콘 |
| 변경 영향 | 회사 전체에 영향 | 해당 제품에 영향 |

- Recall Infinity는 LIMAGINATION의 여러 결과물 중 하나다.
- 제품의 디자인이 회사 전체의 시각 언어나 행동 원칙을 정의하지 않는다.
- 제품은 필요에 따라 독자적인 색상, 말투, 캐릭터, 화면 구조를 가질 수 있다.
- 회사 브랜드를 표시할 때는 승인된 로고와 \`Made with LIMAGINATION\` 서명을 사용한다.
- 회사의 로고·서체·서명은 제품 자산과 혼동되지 않도록 한다.

## 3. 제품 경험 원칙

아래 원칙은 Recall Infinity에만 적용한다.

1. **명료한 도구** — 계획, 복습, 타이머, 통계를 사용자가 빠르게 이해할 수 있어야 한다.
2. **부담을 낮추는 동반자** — 학습 실패를 비난하거나 죄책감을 주지 않는다.
3. **완벽보다 지속성** — 게임 요소와 보상은 학습 흐름을 돕는 수단이지 압박이 아니다.
4. **필요한 순간의 안내** — 다음 행동을 이해하는 데 필요한 정보만 보여준다.
5. **정교한 마감** — 인터랙션·전환·오류 상태를 끝까지 점검한다.

## 4. 제품 UI 방향

### 4.1 구조와 사용성

- 화면의 정보 위계와 간격은 일관되게 유지한다.
- 핵심 동작은 명확하고 예측 가능해야 한다.
- 움직임은 상태 변화를 설명하는 범위에서 사용한다.
- 외부 제품이나 디자인 시스템은 참고 사례로 활용할 수 있으나, 그 원칙을 LIMAGINATION의 회사 신조로 간주하지 않는다.

### 4.2 색상

- 앱의 보라색 \`#8B5CF6\`은 Recall Infinity의 액센트 기준이다.
- 액센트는 상태·강조·제품 고유 순간에 제한적으로 사용한다.
- 배경 전체를 액센트 색으로 채우지 않는다.
- 라이트·다크 테마 모두에서 텍스트와 컨트롤의 대비를 확인한다.
- 이 색상 기준은 다른 LIMAGINATION 제품에 자동 적용하지 않는다.

### 4.3 캐릭터와 마스코트

- 작은 코치 캐릭터와 안테나·미소 모티프는 Recall Infinity 앱의 제품 자산이다.
- 축하·격려·위로 등 필요한 순간에만 반응한다.
- 감시자처럼 행동하거나 사용자를 압박하지 않는다.
- 이 캐릭터를 LIMAGINATION 회사 로고나 회사 공통 마스코트로 사용하지 않는다.

### 4.4 타이포그래피

- 한글 본문은 실제 화면 크기와 사용 환경에서 가독성을 확인한 글꼴을 우선한다.
- Limagination Sans는 브랜드 표현·헤드라인·짧은 강조 문구에 사용할 수 있다.
- 제품의 실제 폰트 스택, 폴백, 웨이트, 캐시 버전은 RecallInfinity 앱 저장소의 구현을 기준으로 한다.
- 과거 문서에는 Recall Sans, Limagination Sans, Pretendard가 혼재한다. 현재 앱 소스를 확인하기 전에는 특정 조합을 확정 규칙으로 취급하지 않는다.

## 6. 제품 문구와 피드백

- 사용자의 미완료 상태를 비난하지 않는다.
- 오류는 원인과 다음 행동을 알려준다.
- 축하 표현은 짧고 과하지 않게 사용한다.
- 코치의 말투와 친근함은 앱 안에서만 적용한다.
- 앱 문구를 회사 공식 발표·채용·대외 문서의 말투 기준으로 사용하지 않는다.

## 7. 배포 서명

앱의 환영 화면이나 설정 화면, 공유 이미지 등에 다음 서명을 사용할 수 있다.

Recall Infinity · Made with LIMAGINATION

Made with LIMAGINATION은 제품의 제작 주체를 표시하는 상위 브랜드 서명이다. 이것이 제품과 회사의 정체성이 같다는 뜻은 아니다.

## 8. 제품 변경 검토

제품 UI나 경험을 변경할 때 확인한다.

1. 학습자가 다음 행동을 이해하기 쉬운가?
2. 불필요한 압박이나 죄책감을 만들지 않는가?
3. 학습 흐름과 꾸준함을 실제로 돕는가?
4. 접근성·가독성·오류 상태를 검증했는가?
5. 회사 브랜드 자산을 사용할 경우 원본 규칙을 지켰는가?

제품 기능과 화면에 관한 결정은 RecallInfinity 저장소에서 관리한다. 회사 철학을 바꾸려면 제품 문서가 아니라 회사 브랜드 헌장을 별도로 개정해야 한다.
