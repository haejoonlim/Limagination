LIMAGINATION SANS — 사용 가이드
================================================================
버전      : 1.2 (전체 한글 11,172자 + 진짜 듀얼 웨이트 + 기호 전수 재건)
배포 버전 : v13 (Regular) / v12 (Bold)   ← 앱 @font-face 캐시버스트와 일치
패밀리명  : Limagination Sans
스타일    : Regular, Bold
설계 철학 : LIMAGINATION 브랜드 헌장 v2.0 — '말랑꾸불' 모던 산세리프
            (호기심에서 시작해 상상으로 태어나, 끝까지 다듬어 잊히지 않는)
제작      : image-to-fonts 추출(라틴/기호) + 자모 합성 엔진(한글 전체)
            + 기호 전수 재건(추출 파이프라인 손상 복구)

1. 포함된 파일
----------------------------------------------------------------
  fonts/LimaginationSans-Regular.ttf     설치용 — Regular (스템 110)
  fonts/LimaginationSans-Regular.woff2   웹용 — Regular (압축)
  fonts/LimaginationSans-Bold.ttf        설치용 — Bold (스템 160)
  fonts/LimaginationSans-Bold.woff2      웹용 — Bold (압축)
  specimen.html                          브라우저 미리보기 페이지
  LimaginationSans_사용가이드.txt          이 문서

  ※ Bold는 별도 빌드된 진짜 웨이트입니다 (자모 엔진 스템 160 + 라틴
    pyclipper 외곽 확장). 앱에서 가짜 볼드(font-synthesis)를 쓰지 않아도 된다.

  ※ 스템은 2026-08-06에 125/165 → 110/160으로 조정됐다 — 작은 크기
    (10~28px)에서 카운터(ㅏ 안쪽·ㅇ 구멍)가 막히지 않는 텍스트 웨이트.

----------------------------------------------------------------
2. 글리프 커버리지
----------------------------------------------------------------
  - 한글 음절 전부 : 11,172자 (초성 19 × 중성 21 × 종성 28)
  - 영문 대소문자  : A–Z, a–z
  - 숫자           : 0–9
  - 기호           : ! ? . , : ; … · — – “ ” ‘ ’ ( ) [ ] { } < > / \ |
                     @ # $ % ^ & * + - = _ ~ ※ ₩ ° ± ÷ × → ← ★ ☆ ○ ● ♥
  - 겹받침 11종    : ㄳ ㄵ ㄶ ㄺ ㄻ ㄼ ㄽ ㄾ ㄿ ㅀ ㅄ

  ※ 기호 전수 재건 (2026-08-06): image-to-fonts 추출 파이프라인이 소스 OTF에서
    기호를 손상시켰던 것을 프리미티브(막대·원·사선·별·하트)로 전부 재건했다.
    - 형상 소실 재건 : % < > × - _ ~ ₩ / # ! [ ] ^ * + = : ; ? 등
    - 잘못 매핑 수정 : ○ … ∞ ≠ ≈ (엉뚱한 글리프에 연결돼 있었음)
    - 중복 제거      : & ( ] { $ + ∞ ○ — 컨투어가 2~5벌 겹쳐 두껍게 보이던 것
                       x-클러스터 dedupe로 1벌만 유지 + 재중앙화 (cx≈300, adv 600)
    - cmap 누락 추가 : ? " ' ♥ ± ° ※ ★ ☆ — – ‘ ’ → ← · ●
    검증: 전 기호 cmap 존재 · 형상 정상 · 라틴/숫자 기준선 정렬 (대문자·숫자
    yMin=0, 소문자 0/descender -240, Bold는 ±20 일관 확장).

----------------------------------------------------------------
3. 설치 방법
----------------------------------------------------------------
  [macOS]
    1. fonts/LimaginationSans-Regular.ttf 더블클릭
    2. Font Book(서체 관리자)이 열리면 [서체 설치] 클릭
    3. 앱(Figma·Pages·Keynote 등)에서 'Limagination Sans' 검색
    ※ 기존에 설치한 버전이 있으면 삭제 후 재설치 (캐시된 옛 폰트가 남으면
      예전 모습이 보인다)

  [Windows]
    1. TTF 파일 우클릭 → [설치] (또는 설치를 눌러 모든 사용자용 설치)
    2. 오피스·포토샵 등에서 'Limagination Sans' 검색

  [iPhone / iPad — Xcode 앱 번들]
    1. Xcode 프로젝트에 TTF 파일을 드래그 (Copy items if needed 체크)
    2. Info.plist 에 UIAppFonts 항목 추가:
         <key>UIAppFonts</key>
         <array><string>LimaginationSans-Regular.ttf</string></array>
       (Bold도 쓰려면 <string>LimaginationSans-Bold.ttf</string> 추가)
    3. 코드에서 사용:
         Swift : UIFont(name: "Limagination Sans", size: 17)
         iOS17+: Font.custom("Limagination Sans", size: 17)

  [웹]
    아래 @font-face 를 CSS에 붙여넣기 (fonts/ 폴더를 사이트에 함께 배포)

----------------------------------------------------------------
4. 웹 사용 — CSS @font-face (v13/v12 기준)
----------------------------------------------------------------
@font-face {
  font-family: 'Limagination Sans';
  src: url('fonts/LimaginationSans-Regular.woff2?v=13') format('woff2');
  font-weight: 400;
  font-style: normal;
  font-display: swap;
  /* 실제 글리프 커버리지와 일치하는 unicode-range (범위 밖은 폴백) */
  unicode-range: U+0020-005F, U+0061-007E, U+00A2-00A3, U+00A5, U+00A7, U+00A9,
                 U+00AB, U+00AE, U+00B0-00B1, U+00B7, U+00BB, U+00D7, U+00F7,
                 U+2013-2014, U+2018-2019, U+201C-201D, U+2022, U+2026, U+2030,
                 U+203B, U+20A9, U+20AC, U+2190, U+2192, U+221E, U+2248, U+2260,
                 U+25CB, U+2605-2606, U+2665;
}
@font-face {
  font-family: 'Limagination Sans';
  src: url('fonts/LimaginationSans-Bold.woff2?v=12') format('woff2');
  font-weight: 700;
  font-style: normal;
  font-display: swap;
  unicode-range: U+0020-005F, U+0061-007E, U+00A2-00A3, U+00A5, U+00A7, U+00A9,
                 U+00AB, U+00AE, U+00B0-00B1, U+00B7, U+00BB, U+00D7, U+00F7,
                 U+2013-2014, U+2018-2019, U+201C-201D, U+2022, U+2026, U+2030,
                 U+203B, U+20A9, U+20AC, U+2190, U+2192, U+221E, U+2248, U+2260,
                 U+25CB, U+2605-2606, U+2665;
}

/* 폰트 스택 예시 — 라틴·숫자·기호는 Limagination Sans, 한글은 Pretendard */
body { font-family: 'Limagination Sans', 'Pretendard', -apple-system, sans-serif; }

  ※ 앱(Recall Infinity)에서는 한글을 Pretendard로 폴백시키고 Limagination Sans를
    라틴·숫자·기호·로고·서명(브랜드 순간)에 사용한다 (한글 전체 TTF는 디스플레이
    ·포스터·로고용으로 이 패키지에 보존). 전체 한글을 브랜드 폰트로 쓰려면
    unicode-range에 U+AC00-D7A3 를 추가하면 된다.

5. 굵기(볼드) 안내
----------------------------------------------------------------
진짜 Bold 웨이트가 포함되어 있다 (자모 엔진 스템 160 + 라틴 pyclipper 외곽
확장, OS/2 weight 700). Bold TTF/woff2를 함께 배포하면 가짜 볼드(font-synthesis)
없이 굵은 텍스트가 브랜드 톤 그대로 두꺼워진다. 톤 조정 시
scripts/recall-font/build_limagination_full.py 의 STEM 상수 하나만 바꾸면
전 자모·기호에 일괄 반영된다.

6. 배포 버전 이력 (캐시버스트 ?v= 와 일치)
----------------------------------------------------------------
  v5/v4   — 한글 와인딩·라틴 기준선 수정
  v7/v6   — 기호 전수 재건 (누락·잘못매핑·형상손상 27종 프리미티브 재건 +
            중복 컨투어 dedupe + unicode-range 실커버리지 갱신)
  v12/v11 — 한글 비례 수정 (ㅏ족 갈고리 높이 54.5/67.5%, ㄱ족 세로획 좌측
            이동 — '⊥'·떠 있는 갈고리 인상 제거)
  v13/v12 — ● (U+25CF) 추가 + Bold 전수 감사 통과  ← 현재

  ※ unicode-range나 글꼴 파일을 바꿀 때마다 ?v= 쿼리를 반드시 올려야
    브라우저 캐시가 갱신된다.
