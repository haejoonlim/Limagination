1. 경영 요약 (Executive Summary)
----------------------------------------------------------------

[매니페스토 — 회사의 가장 위 문장]
  We Imagine Before We Create.
  우리는 만들기 전에 먼저 상상한다. 모든 것은 상상에서 시작된다.

LIMAGINATION은 "상상(Imagination)에 세련됨을 더하는" 제품 회사다.
첫 제품 Recall Infinity(AI 학습 플래너)를 필두로, 사용자의 일상을
명료하게(Apple), 부드럽게(Recall), 잊히지 않게(LIMAGINATION)
만드는 화면을 만든다.

  이름     LIMAGINATION = LIM + IMAGINATION
           (창업자의 손글씨 + 상상력 — 개인 브랜드에서 출발한 회사)

  한 문장  상상에서 태어난, 부드럽게 함께하는, 어디서나 세련된 제품을 만드는 회사.

  약속    우리가 만드는 모든 화면은 명료하고, 따뜻하고, 잊히지 않는다.
           (Clear · Warm · Memorable)

  슬로건  "Made with LIMAGINATION"
           — 앱 푸터·환영 화면에 이미 새겨진 브랜드 서명

핵심 한 줄: 기반은 애플처럼, 마음은 리콜처럼, 개성은 리매지네이션처럼.

2. 브랜드 정체성 (Brand Identity)
----------------------------------------------------------------

2.1 이름 스토리
  - LIM         : 창업자의 서명 — 브랜드는 '사람'에서 시작한다
  - IMAGINATION : 회사의 원료 — 모든 제품은 상상에서 태어난다
  - 조합 규칙    : 대문자 LIM + 대문자 IMAGINATION = 개인과 상상의 결합,
                  'Imagine'의 울림

  - 읽는 법 : 리매지네이션 (LIM + AGINATION)
  - 영문 표기: LIMAGINATION (전체 대문자 고정 — 로고·서명·푸터)
  - 폰트 서명: "Made with LIMAGINATION" — 모든 제품·아티팩트에 새긴다

2.2 우리가 믿는 것 (What We Believe)
  - 기술보다 사람을 믿는다.
  - 답보다 질문을 믿는다.
  - 완성보다 가능성을 믿는다.
  - 상상은 특별한 사람만의 능력이 아니라,
    모든 사람이 가진 가장 강력한 능력이다.

2.3 우리의 영역 (Our Domain)
  LIMAGINATION은 특정 사업을 정의하지 않는다.
  사람들이 생각하고, 상상하고, 배우고, 창조하고, 표현하는 모든 경험이
  우리의 영역이다. 만드는 것은 달라질 수 있지만, 언제나 사람의 가능성을
  넓히는 경험이어야 한다. (AI · 앱 · 교육 · 디자인 · 하드웨어 — 무엇이든 가능)

2.4 미션 · 비전 · 가치
  - 미션   : 상상을 새로운 가능성으로 연결한다
  - 비전   : 세상에서 가장 많은 상상이 시작되는 브랜드
  - 가치   : 5신조 — 상상 · 새로움 · 유연함 · 독특함 · 세련됨
  - 운영 원리: 통합 신조 3층위 (아래 3장) — 구조는 절대 불변

2.5 태그라인 후보 (우선순위순)
  1. Made with LIMAGINATION — 제품 서명 (현재 사용 중)
  2. We Imagine Before We Create. — 브랜드 매니페스토
  3. "상상에 세련됨을." — 국문 브랜드 슬로건
  4. "기반은 견고하게, 마음은 부드럽게, 개성은 독특하게." — 내부 모토

3. 브랜드 DNA — 통합 신조 (이 회사의 설계 헌장)
----------------------------------------------------------------
아래는 DESIGN_CREED_REPORT.md의 핵심이다. 모든 제품·화면·문구는
이 DNA를 통과해야 한다.

3.1 세 신조의 역할 분담
  - Apple        : 구조 — 명료함·위임·깊이          → 신뢰, 정밀함, "프리미엄다움"
  - Recall       : 마음 — 공부를 부드럽게, 함께     → 따뜻함, 친근함, "왜 쓰는지"
  - LIMAGINATION : 개성 — 상상·새로움·유연함·독특함·세련됨 → 차별성, 기억, "이 회사만의 것"

3.2 3층위 프레임워크 (핵심 모델)
  ┌─────────────────────────────────────────────┐
  │  L3 · 시그니처 (LIMAGINATION)                │  독특함·새로움·상상
  │    — 브랜드 손글씨: Limagination Sans,        │
  │      마스코트, 축하 모션, "여기만의" 순간      │
  │  ─────────────────────────────────────────── │
  │  L2 · 성격 (Recall)                          │  부드러움·따뜻함·함께
  │    — 둥근 모서리, 보라, AI 코치 목소리,        │
  │      게임 요소의 가벼운 배치                   │
  │  ─────────────────────────────────────────── │
  │  L1 · 구조 (Apple)                           │  명료·위임·깊이
  │    — 격자·스페이싱·타이포·계층·스프링 물리      │
  │      절대 어기지 않는 하드 코드                │
  └─────────────────────────────────────────────┘

  핵심: L1을 어기면 버그. L2를 어기면 차가움. L3가 없으면 평범함.

3.3 브랜드 원칙 — LIMAGINATION만의 5가지
  - Imagine First       : 항상 먼저 상상한다       → 상상에서 시작했는가?
  - Make it Human       : 사람을 중심에 둔다       → 사람의 가능성을 넓히는가?
  - Keep it Clear       : 복잡함은 줄인다          → 쉽게 이해되는가?
  - Refine Relentlessly : 끝없이 다듬는다          → 끝까지 다듬었는가?
  - Leave Wonder        : 작은 놀라움을 남긴다     → 기억에 남는가?

3.4 행동 — 직원이 그대로 따르는 것
  우리는 질문한다 · 탐험한다 · 상상한다 · 만든다 · 다듬는다 · 공유한다.

3.5 긴장 해소 원칙
  - 절제 vs 독특함    : 독특함은 구조를 건드리지 않고 디테일에만 산다
  - 전문성 vs 귀여움  : 도구 동작은 전문적으로, 감성 요소만 부드럽게
  - 일관성 vs 새로움  : 새로움은 기존 패턴 위의 변주로만
  - 단일 원칙         : "언제나 사용자에게 가장 부드러운 쪽이 승리한다"
                       — 독특함이 명료함을 해치면 독특함이 물러난다

3.6 실전 판정 — 3문 체크리스트
  1. 명료한가?   (Apple)        — 어떤 크기·상태에서도 읽히는가?
  2. 부드러운가? (Recall)       — 두렵지 않고, 격려하며, 판단하지 않는가?
  3. 독특한가?   (LIMAGINATION) — 기억에 남지만 소음은 아닌가?

  - 3개 모두 YES → 진행
  - "독특함"이 "명료함"을 해침 → 독특함을 한 단계 내린다 (L3 → L2)
  - "따뜻함"이 "전문성"을 해침 → 따뜻함을 감성 요소로만 이동

4. 브랜드 페르소나 (Brand Personality)
----------------------------------------------------------------
브랜드는 '따뜻한 상상력'이다 — 똑똑하고, 상상력 넘치고, 조용히 세련된
친구. 가르치려 들지 않고, 함께 상상하고, 결과물은 언제나 깔끔하다.

4.1 5신조를 성격으로
  - 상상   : "이거 이렇게도 만들 수 있지 않을까?"      (금지: 복붙 제품, 뻔한 화면)
  - 새로움 : 익숙한 패턴의 신선한 변주                  (금지: 익숙함에 안주)
  - 유연함 : 화면·기기·사용자에 따라 스스로 변형        (금지: 고정된 한 가지 방식)
  - 독특함 : 마스코트·말버릇·디테일의 시그니처          (금지: 따라쟁이, 평범함)
  - 세련됨 : 완성된 마감, 조잡함 배격                  (금지: 급조, 어수선함)

4.2 목소리와 톤 (Voice & Tone)
  - 제품 UI 복사   : 짧고, 명확하고(Apple), 따뜻하게(Recall) — "천천히 해도 괜찮아"
  - 오류 메시지    : 탓하지 않고, 다음 단계를 제안 — "잠깐만, 다시 시도해볼까?"
  - 축하          : 과하지 않게, 진심으로 — "와! 정말 잘했어! 🌱"
  - 브랜드 마케팅  : 자신감 있되 자랑하지 않기 — "Made with LIMAGINATION"

  금지 언어: 유죄감 유발("왜 안 했어요"), 봇 말투("처리되었습니다"),
            자만("우리가 최고"), 장식 남발(이모지 3개 초과 금지).

5. 비주얼 아이덴티티 (Visual Identity)
----------------------------------------------------------------

5.1 로고 방향
  - 단어마크: 전대문 LIMAGINATION + "Made with LIMAGINATION" 서명 세트
  - 심볼    : Recall 마스코트(동그란 얼굴 + 안테나)를 브랜드 얼굴로 승격
  - 폰트    : Limagination Sans (L3 시그니처) — 로고·히어로·브랜드 순간
  - 원칙    : L1 구조(그리드·비례) 안에서 L3 디테일(둥근·독특한 획)을 살린다

5.2 컬러 시스템 (3층위 토큰)
  - L1 : 화면 기반(라이트/다크) — iOS 시스템 컬러 (--bg-canvas, --text-primary 등)
  - L2 : 브랜드 액센트 — 보라 #8B5CF6 — 배경이 아닌 액센트로만
  - L3 : 시그니처 순간 — 보라→인디고 그라데이션·글로우 (축하·레벨업·리그 승격)

  - 액센트 규칙: 보라는 상태·강조·브랜드 순간에만, 면적 20% 이내
  - 두 테마 모두 WCAG AA 대비 유지 (이미 토큰에서 보장)

5.3 타이포그래피 (두 폰트의 역할 분담)
  - Limagination Sans : L3 — 로고·브랜드 히어로·이벤트·축하 (세련+독특)
  - Recall Sans       : L1+L2 — 앱 본문·숫자·타이머 (부드러운 전문성)
  - Pretendard        : L1 — 한글 기본 품질 (셀프호스팅)

5.4 마스코트
  - 정체성: "상상력이 깃든 작은 코치" — 안테나(상상의 신호) + 미소
  - 행동 규칙: 축하·격려·위로에 반응, 감시자 역할 금지, 소음 금지
  - 사용: 앱 내 L2/L3 요소 + 브랜드 SNS·이벤트의 얼굴

6. 제품 브랜딩 적용 (첫 제품: Recall Infinity)
----------------------------------------------------------------

6.1 플래그십 제품의 브랜드 포지셔닝
  어떤 제품?  AI 학습 플래너 — SM-2 복습, 집중 타이머, 학습 리그
  왜 다른가?  무섭지 않은 학습 (L2) + 세련된 도구 (L1) + 독특한 코치 (L3)
  한 줄 카피  "공부를 부드럽게, 함께" — made with LIMAGINATION

6.2 화면별 브랜드 적용 지도
  화면   | L1 (Apple)          | L2 (Recall)        | L3 (LIMAGINATION)
  홈     | 타임라인 그리드·위젯 | 위젯 다이얼·마스코트 | 축하 모션·브랜드 폰트 순간
  통계   | 차트 명료성          | 보라 강조           | 히트맵·리그 시그니처
  타이머 | 정밀한 도구          | "천천히 해도 괜찮아" | 완료 폭죽
  AI 코치| 명확한 답변          | 반말 따뜻함         | 독특한 말버릇 "한 걸음 성장했네 🌱"
  설정   | 그룹 테이블          | 토글의 보라         | — (브랜드는 조용히)

6.3 배포 서명
  - 환영 화면·설정 푸터    : "Recall Infinity · Made with LIMAGINATION"
  - 백업·공유·스크린샷 워터마크: "Made with LIMAGINATION"

7. 브랜드 가버넌스 (Brand Governance)
----------------------------------------------------------------

7.1 운영 원칙
  1. 모든 기능·화면은 3문 체크리스트 통과 필수
  2. 모든 결정 전에 헌장의 3문(The Three Questions) —
     가능성·상상·완성도 — 에 YES를 얻는다
  3. L1(구조) 변경은 문서화 필요 — 명료함이 곧 브랜드의 신뢰
  4. L3(시그니처)는 희소하게 — 자주 쓰면 평범해진다
  5. 브랜드 자산(폰트·마스코트·컬러)은 단일 저장소에서 관리

7.2 브랜드 금지 목록 (Anti-Patterns)
  - 구조를 무너뜨리는 독특함(비대칭 폭주 등)   : L3가 L1을 침범
  - 유죄감·비교 언어                          : L2 위반
  - 차가운 오류 메시지("잘못된 입력입니다")    : L2 위반
  - 장식적 과잉(그라데이션 남발, 이모지 폭주)  : L1·L3 위반
  - 한 화면에 시그니처 3개 이상                : L3 희소성 위반
  - 브랜드 무단 변경(보라를 다른 색으로)       : 정체성 훼손
  - 만들기부터 시작하기(상상 없는 창조)        : 헌장 매니페스토 위반 — 항상 Imagine First

7.3 브랜드 리뷰 프로세스
  상상(Idea) → 3문 체크(가능성·상상·완성도) → 3문 체크리스트(명료·부드러움·독특)
  → 디자인 → L1/L2/L3 층위 라벨링 → 구현 → QA(대비·접근성·모션 절제)
  → 릴리스 → "Made with LIMAGINATION" 서명

9. 부록 — 신조 원문

[Apple HIG]
  명료함(Clarity) — 어떤 크기에서도 읽히는 타이포.
  위임(Deference) — UI는 콘텐츠와 경쟁하지 않는다.
  깊이(Depth) — 위계가 층으로 드러난다.
  "Design is how it works."

[Recall]
  "공부를 부드럽게, 함께." — 격려하는 AI 학습 동반자.
  완벽보다 꾸준함. 게임 요소는 동기부여이지 압박이 아니다.

[LIMAGINATION (헌장 v2.0)]
  매니페스토 : "We Imagine Before We Create. — 우리는 만들기 전에 먼저 상상한다."
  원칙      : Imagine First · Make it Human · Keep it Clear
              · Refine Relentlessly · Leave Wonder
  행동      : 질문한다 · 탐험한다 · 상상한다 · 만든다 · 다듬는다 · 공유한다
  상상의 순환: 호기심 → 상상 → 창조 → 다듬음 → 의미
  믿음      : 기술보다 사람, 답보다 질문, 완성보다 가능성
  서명      : "Made with LIMAGINATION" — 제작자가 아니라 철학을 의미한다

[통합 정의]
  "상상에서 태어난, 부드럽게 함께하는, 어디서나 세련된 학습 동반자."
  기반은 애플처럼, 마음은 리콜처럼, 개성은 리매지네이션처럼.
